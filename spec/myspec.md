# 자기소개 원페이지 사이트 제작 요청 (Spec)

아래 사양대로 개인 자기소개 웹사이트를 만들어 주세요.
나는 코딩을 전혀 모르므로, 완성 후 **로컬 실행 방법과 Vercel 배포 방법을 단계별로** 알려주세요.

---

## 1. 프로젝트 개요

- **목적**: IT 기업 대표 겸 대학 겸임교수의 비즈니스용 개인 프로필 사이트
- **형태**: 원 페이지(One-page) 세로 스크롤 사이트. 상단 네비게이션 클릭 시 해당 섹션으로 부드럽게 스크롤 이동
- **언어**: 한국어
- **분량**: 간단하게. 섹션 4개 + 푸터

## 2. 기술 스택 (Vercel 배포 전제)

- **Next.js (App Router) + TypeScript**
- **Tailwind CSS** (스타일링)
- **Framer Motion** (스크롤/등장 애니메이션)
- 별도 백엔드, DB, 로그인 없음. 정적 콘텐츠만
- `npm run dev`로 로컬 실행, GitHub 연동 후 Vercel에 그대로 배포 가능한 구조로
- 모든 텍스트 콘텐츠는 **하나의 파일(예: `data/content.ts`)에 모아서** 정의할 것 — 내가 나중에 코드 몰라도 이 파일만 고치면 내용이 바뀌도록. 각 항목에 한국어 주석으로 "여기를 수정하세요" 표시

## 3. 페이지 구성 (위에서부터 순서대로)

### 3-1. 고정 네비게이션 바
- 좌측: 이름 로고(텍스트), 우측: 메뉴 4개 — **홈 / 자기소개 / 취미 / 포트폴리오**
- 스크롤을 내리면 배경이 반투명 블러(glassmorphism)로 변하며 상단에 고정
- 현재 보고 있는 섹션의 메뉴가 하이라이트(스크롤 스파이)
- 모바일에서는 햄버거 메뉴

### 3-2. 홈 (Hero)
- 화면 전체 높이(100vh)
- 큰 타이포그래피로 이름 + 한 줄 소개 (더미: "홍길동 — 기술로 학회를 연결합니다")
- 페이지 로드 시 텍스트가 순차적으로 아래에서 위로 부드럽게 등장
- 배경: 하늘색 계열의 은은한 그라데이션 + 천천히 움직이는 부드러운 블러 원(ambient blob) 1~2개
- 하단 중앙에 "스크롤" 유도 화살표 (천천히 까딱이는 모션)

### 3-3. 자기소개 (About)
- 좌: 프로필 이미지 placeholder(회색 박스 + "프로필 사진" 텍스트, 추후 교체 예정), 우: 소개 텍스트
- 더미 텍스트: 직함 2개(기업 대표 / 겸임교수), 짧은 소개 문단 1개, 핵심 키워드 3~4개(예: 소프트웨어 개발, 교육, 학회 시스템)
- 경력/이력 3~4줄을 연도 + 내용 형태의 간단한 타임라인으로 (더미 데이터)
- 스크롤로 섹션 진입 시 요소들이 순차적으로 fade-in + 살짝 위로 올라오는 애니메이션

### 3-4. 취미 (Hobbies)
- 카드 3~4개 그리드 (더미: 사진, 독서, 여행, 운동 등)
- 각 카드: 이미지 placeholder + 제목 + 한 줄 설명
- 호버 시 카드가 살짝 떠오르는(translate + shadow) 마이크로 인터랙션
- 스크롤 진입 시 카드들이 시차를 두고(stagger) 등장

### 3-5. 포트폴리오 (Portfolio)
- 프로젝트 카드 3~6개 그리드 (더미 프로젝트명, 한 줄 설명, 기술 태그 2~3개)
- 각 카드: 썸네일 placeholder + 제목 + 설명 + 태그
- 호버 시 썸네일이 미세하게 확대
- 카드 클릭 시 동작은 없어도 됨 (링크는 나중에 추가)

### 3-6. 푸터
- 이메일 placeholder(`email@example.com`), 저작권 표기
- SNS 아이콘 2~3개 placeholder (링크는 `#`)

## 4. 디자인 가이드

### 색상 (하늘색 중심)
- 주조색: 하늘색 계열. 예시 토큰:
  - Primary: `#38BDF8` (sky-400)
  - Primary Deep: `#0284C7` (sky-600) — 버튼, 강조
  - 배경: `#F8FBFD` (아주 옅은 청백색)
  - 텍스트: `#0F172A` (진네이비), 보조 텍스트: `#64748B`
- 전체적으로 밝고 깨끗한 톤. 하늘색은 포인트로 절제해서 사용하고, 본문 영역은 여백 많고 차분하게 (비즈니스 프로필이므로 과한 색 사용 금지)

### 타이포그래피
- 한글 웹폰트 **Pretendard** 사용 (CDN)
- Hero 제목은 크고 굵게(예: 56~72px, font-bold), 본문은 16~18px, 자간/행간 여유 있게

### 애니메이션 (애플 사이트 느낌)
- 핵심: **스크롤 기반 등장 애니메이션**. 섹션이 뷰포트에 들어올 때 opacity 0→1, y축 20~30px 이동, duration 0.6~0.8초, ease-out
- 요소가 여러 개인 곳(카드, 타임라인)은 0.1초 간격 stagger
- 과하지 않게: 회전, 3D, 번쩍이는 효과 금지. 부드럽고 절제된 모션만
- `prefers-reduced-motion` 설정 시 애니메이션 비활성화

### 이미지 placeholder 규칙
- 모든 이미지는 회색(#E2E8F0) 박스 + 중앙에 안내 텍스트("프로필 사진", "취미 이미지 1" 등) 형태로
- 나중에 실제 이미지 파일로 교체하기 쉽도록, 이미지 경로도 content 파일에서 관리

## 5. 품질 요구사항

- 반응형: 모바일(375px)~데스크탑(1440px) 모두 깨지지 않게
- 시맨틱 HTML, 각 섹션에 id 부여(`#home`, `#about`, `#hobbies`, `#portfolio`)
- 기본 SEO: title, description 메타 태그 (더미)
- Lighthouse 성능을 해치는 무거운 라이브러리 추가 금지 (Framer Motion 외 애니메이션 라이브러리 불필요)

## 6. 완성 후 요청사항

1. 프로젝트 폴더 구조 간단 설명
2. 내가 직접 수정할 파일(`data/content.ts`)의 수정 방법 예시
3. 로컬 실행 방법 (`npm install` → `npm run dev`)
4. GitHub에 올리고 Vercel에 배포하는 방법을 비개발자 기준 단계별로
